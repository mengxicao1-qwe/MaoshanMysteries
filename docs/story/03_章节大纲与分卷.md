## 1. 总览

**书名**：《茅山秘录·诡异录》
**类型**：志怪悬疑 / 道士办案 / 时间循环推理解谜
**主角**：道士·**苏景玄**（上清派第七十四代"守录人"，职名"校录"）
**主线**：以茅山为片区的"诡异事件"处理实录，一路查到最后，发现自己在跟一门**改字的人**下棋。

**一句话主线**：
> 一个最会认字的道士，被派去处理茅山片区各种诡异事件；他查出的每一个真相，都指向同一件事——**有人在改书写这些真相的那本书。**

**结构**：五卷十案，一案 = 一处现场 = 一个被改掉的字。
前八案按古史时间顺序（西汉 → 东晋 → 南朝 → 唐 → 宋 → 元明 → 清 → 近现代）各取一件真实史事/实物为原型；卷五回收全部伏线，落在华阳洞。

## 3. 五卷结构

### 卷一《校录》（案一、案二）

- **主角状态**：刚领度牒，被派茅山片区，带一本空白《诡异录》抄本。他以为这工作是"登记"。
- **玩家认知**：诡异事件 = 灵异现象。
- **本卷真相**：有人在**有组织地修字**。案二末尾第一次出现"补录人"三个字。
- **卷末死线**：十二月二日期会。
- **留下的问题**：他们修字是为了什么？

### 卷二《寻真迹》（案三、案四）

- **主角状态**：开始"辨笔"，把工作方法从"驱邪"改成"查证"。
- **玩家认知**：不再是灵异，是**文书的犯罪现场**。
- **本卷真相**：篡录者的动机不是钱——他们在"修订"，且真的相信自己在做善事。案四做实"空缺的名籍"：名籍上被划掉的人，会同时从记录和记忆里淡出。
- **卷末死线**：三月十八期会。
- **留下的问题**：被划掉的人去哪了？谁在替这一代签名？

### 卷三《启封》（案五、案六）

- **主角状态**：第一次面对**封印实体**，付出最重代价（案五失掉一段少年记忆）。
- **玩家认知**：秘录 = 文 + 物 + 地。篡录者已在收集"物"。
- **本卷真相**：三件套封印机制，以及"传派碑"上多出来的那一代——**有人在谱系里插了一行**。
- **卷末死线**：十二月初二。
- **留下的问题**：插进来的那一代，是谁。

### 卷四《家事》（案七、案八）

- **主角状态**：开始怀疑自己的师承。案八末尾，他在自己度牒的存根上发现一个不属于自己的笔迹。
- **玩家认知**：反派有名有姓、有学问、受人尊敬，甚至救过人。
- **本卷真相**：当代"补录人"之首是**受人尊敬的校勘学者**；他的祖父辈是采办，他自己是学者——他比谁都清楚祖上在造假，所以他决定"把假的做成真的"。
- **卷末死线**：三月十八期会。
- **留下的问题**：主角自己是不是也在一份被改过的谱里。

### 卷五《第一行》（案九、案十）

- **主角状态**：从"守录"走到"证录"——他不再假设秘录是完整的，但他仍选择守它。
- **玩家认知**：全盘。
- **本卷真相**：
  - 案九：篡录者要的不是毁掉秘录，而是**补全**它；首领自认在救茅山（因为茅山的确断了代、的确有假经文、的确有被追奉的第一行）。
  - 案十：删掉第一行不会解放任何人——只会让"名籍"成为空白，而空白由会写字的人来填。主角的胜利方式：**证明第一行本来就在**（用白鹄、民谣、期会日、以及大司命君的地官属籍为证）。
- **终局**：主角没有杀掉反派，而是完成了一次**公开的、有见证人的校勘**——把每一处改动连改动的理由一起照原样记下来，附在原书之后。**"秘录"从此不是一份干净的记录，而是一份带校勘记的记录。**这是他能给的最大诚实。
- **代价**：他放弃了"名籍"上原本可以给自己写的那一笔——他不再有可能例外。书名"秘录"的"秘"，到此为止。

## 4. 案件统一模板（全体写作成员必须遵守）

```
## 案N 《案名》
### 一句话钩子
### 现实现场（当代）
### 余页（时间循环段）
      — 起始时间 / 时长 / 循环触发点 / 玩家在每一遍里能改变什么
### 活人动线（NPC 名单）
      — 每人：姓名·身份 / 时辰地点 / 可对话要点 / 他知道什么·瞒什么

      — 逐条标注 `_sources_古史素材考.md` 的编号（如 古史 1.1）
### 缝
      — 被改掉的那一个字/一件物/一个日期 + 改成这个的理由（理由必须站得住）
### 证据链
      — 4–6 环，每环写：获得方式 → 证明什么 → 缺了它会误判成什么

      — 取自 古史 2.x（存思 / 叩齿咽津行气咒祝 / 服饵断谷 / 存思日月星）

      — 按 铁律二"不许宣泄" 付什么
### 真相
      — 古史层一段 + 当代层一段
### 卷末回收
      — 留下的伏笔 + 死线是否落在三月十八 / 十二月初二
```

## 7. 叙事时间轴与期会日分配（**合稿裁定，全体以本表为准**）

期会日只有两个（古史 1.1：**三月十八**、**十二月二日**），而"期会日必须有事"（世界观 §6.2 禁令 6）。
裁定原则两条：
1. **一卷之内，期会日可被"占"两次，但每卷的卷末死线必须落在期会日上**；
2. 相邻两案若共用同一条死线，则它们必须是**同一条时间线上的连续事件**（这是允许的，且更有张力）。

| 卷二《寻真迹》 | 三《石井栏夜话》、四《镇星失名》 | 三月十八（案三于三月十一结案，余下七日全给案四）→ 案四仪式即在**三月十八午正** | ✅ **三月十八** |

**"年"的处理**：卷与卷之间的年份流动是叙事性的，正文**不必给出确切公元年份**（主角始终 24–25 岁，见 `02_主角与人物设定.md` §2.1）。
读者感受到的时间感应来自"期会日又到了"这一重复节奏，而不是日历。

> **追加裁定（针对 baoming 与真系的合稿询问）**：
> - 案五并非卷末，其结案落在三月十八是**刻意的**——它把"期会日不可空"从卷末死线变成**常在的压力源**；
> - 案七与案八**共用三月十八**是批准的设计，理由见上表：案七把这一天找回来，案八在这一天用掉它，**"死线同时是解法生效的窗口"**（期会日录最薄，最薄处登记最易被认）。这条设计要点在合稿中保留，不修正。
