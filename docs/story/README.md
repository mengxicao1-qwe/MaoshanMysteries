# 《茅山秘录·诡异录》— 游戏剧情故事（总索引）

> 以《茅山秘录》（《茅山志》《真诰》等茅山上清派古史）为原型创作的**志怪悬疑剧情**。
> 主角身份：**道士**（上清派第七十四代·职名"校录"）。主线：**解决各种诡异事件**。
> 本目录是完整交付物；全部文档为中文，可直接进入下一阶段的实现（数据表、对话树、场景）。

---

## 1. 一句话故事

> 一个最会认字的道士，被派去处理茅山片区的各种诡异事件。
> 他查出的每一个真相，都指向同一件事——**有人在改书写这些真相的那本书。**

**世界观内核**：道门相信人的生死祸福由"地官属籍"掌管（茅山太史：茅盈受封**大司命君**，"统领地官属籍，试校群仙，关决生死"）。
地官属籍不可改，但**属籍的副本**要有人抄、有人管、有人藏在山里——这份副本叫"**秘录**"。
秘录 = **文**（谱录纪传）+ **物**（玉印·玉圭·玉符·玉简）+ **地**（华阳洞石刻·睹星门）三样合起来才完整：
**文是目录，物是钥匙，地是锁。**
于是世上有两种道士：**守录**的把秘录照原样抄下去；**篡录**的发现改掉录上一个字，就能改掉一个人的生死。
主线就是守录者与篡录者。而主角一开始根本不知道自己在跟谁下棋。

## 2. 三条铁律（全部诡异事件的共同成因）

| 铁律 | 内容 | 玩法/叙事作用 |
| --- | --- | --- |
| **一·录改了，籍就松了** | 篡录者动秘录，会让某一处「名与实」裂开一条缝。缝在日子上 → **某一个日期被从所有人的记忆里剪掉** | 这就是**时间循环**的世界观解释：反复播放的时段是"**余页**"——秘录被改后没写死的一页，等人来补 |
| **二·不许宣泄** | 茅盈受王君之赐时立坛结盟、"不许宣泄"。把秘录内容说给不该听的人，那段内容就从句子里脱落、落到听者身上 | **解释真相要付费**：主角每次向同伴说明，都要失去一段自己的记忆 |
| **三·期会日不可空** | 每年**三月十八**、**十二月二日**期会。这两天在籍上被写得最重，重到无法一次写完 → 最薄 | 每个案件卷的**死线**都落在这两天 |

**主角的道法体系**：上清派本色是**存思**（存神）。本作推到极致——既然身内之神可存思，身外之"余页"也可存思。
主角的独门本领不是斗法，是**辨笔**：一眼看出哪一笔不是原手写的。**他不是最能打的道士，是最会认字的道士。**

## 5. 反派与终局

- **篡录者**源出东晋**王灵期**一脉：他认为旧文太简，"窃加损益，盛其藻丽"，结果"许、王齐辔，真伪比踪"。
  这门手艺传下来，祖训四个字：**"盛其藻丽"**。他们不认为自己在造假，他们认为自己在**修订**。
- **当代首领闻仲连**（校勘学者）：祖父是采办，父亲靠这批东西混成"书香门第"。
  他从小就知道自己家的学问是假的，所以——
  > **"祖上做假，我做真。同一条路，走完就干净了。"**
  他的方法完全合法：**出版、数字化、引用、共识**。他真正的武器是"**大家都信**"。
- **他的终极计划**：把"第一行"（三茅真君）从秘录里删掉。而他的论据**在文献学上是真的**——
  三茅真君**确实**是追奉的、**确实**在代次之外、**确实**早于上清经的造作。
- **主角的胜利方式（不是打倒他）**：证明"第一行本来就在"——
  它的**职务**（大司命君，统领地官属籍，关决生死）跨越西汉、东晋、南朝、元代连续不断。
  > "你说得对，第一行是添上去的。可它不是一辈分，**它是一份工**。"
- **终局**：主角把每一处改动**连同改动的理由**照原样记下来，附在原书之后，当众署名受录。
  **秘录从此不是一份干净的记录，而是一份带校勘记的记录。**这是他所能给的最大诚实。
  代价：他放弃给自己在名籍上写一笔的机会；**终局之后，只有穆青、阿沅和那份校勘记记得他。**

## 7. 与工程对接（现状）

现有核心系统三件套（见 [`../../README.md`](../../README.md)）**不需要任何改动**，剧情通过"换数据文件 + 加玩法层脚本"落地：

| 世界观 | 工程 |
| --- | --- |
| 余页 / 第几遍存思 | `TimeLoopManager`（`get_loop_index()` / `signal loop_reset`） |
| 余页长度（各案不同） | `data/scenarios/case_NN_*.json` 的 `meta.loop_duration_seconds` |
| 录中所得（线索，跨遍保留） | `PersistentMemoryManager.add_clue(id, loop_index)` |
| 活人动线（每遍一致 → 差异即线索） | `NPCTimelineParser` + `data/npc_timelines.json`（各案追加 `meta.secret`） |
| 心灯（唯一新增的轻量组件） | `scripts/entities/heart_lamp.gd`（只订阅信号，不动核心层） |

详细字段规格、`clue_id` 命名规范、三种线索状态、可测试断言，见 [`09_系统映射与数据规格.md`](09_系统映射与数据规格.md)。

1. **时间轴统一**：期会日只有两个，故**卷内可占两次、卷末死线必须落在期会日**；案七与案八**共用三月十八**是批准设计——案七把这一天找回来，案八在这一天用掉它。
2. **案九日期修正**：原写"秋"，与"死线十二月初二"冲突，改为**十一月三十**。
3. **重名消歧**：案七石匠原用"邱德茂／邱雪"，与案一石匠"邱德茂"重名，**全文改为邱德茂／邱雪**。
4. **未采用角色清理**：预设的"何九""裴文"未被任何案件采用，功能已并入案一邱德茂、案七怀怀安；`02` §7.3 已存档说明。
5. **"雨师"废弃**：大纲原用此词，写手以其不见于古史而改以"领雨／应雨者"表述，大纲已同步修正。
6. **度牒"让出一格"机制锁定**：把案四（主角让格）→ 案八（存根上的笔迹）→ 案九（那一格已被填上）串成同一条链，并写明**它靠"照录制度"生效，而非伪造**。
7. **摊录条款**：xuanjian 提出的"摊开原件替口述"机制**附三条硬约束准用**（须有原件、只对当事人、读的人自己付代价），防止架空铁律二。

**已结清的质量门**：
- 十案**全部**采用统一 12 小节模板；案名与骨架一致；
- 每案均含「余页」（起始/时长/触发点/每遍可变量）、「活人动线」（可直接落 JSON）、「证据链」（每环含"缺了它会误判成什么"）、「道法解法」（先证后仪，仪式只作确认）、「代价」（铁律二）；
- 自造术语 **40 项全部登记**，1 项废弃、1 项附条件、2 项上收为全书核心（**留白**、**石上之录**）；**未登记使用 0 项**；
- 各案数据表（案五/六/七/八）已通过 JSON 解析验证，字段与 `NPCTimelineParser` 兼容。
