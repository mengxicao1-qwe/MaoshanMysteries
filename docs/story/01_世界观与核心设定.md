# 世界观设定：录、籍、名

> 依赖：`_sources_古史素材考.md`。所有设定项后括号内为该文件中的出处母题。
> 本文件是全部案件文档的**设定上限**：案件可以细化，不得新增与本文件冲突的世界规则。

---

## 1. 一句话世界观

**茅山秘录，是给鬼看的户口册。**

道门古来相信，人的祸福生死由"地官属籍"掌管——西汉茅盈受封**大司命君**，"统领地官属籍，试校群仙，关决生死"（古史 1.1）。
地官属籍不可改，但**属籍的副本**要有人抄、有人管、有人藏在山里。这份副本，道门内部称为"**秘录**"。

秘录不是一本书，是一**套**东西：文（《茅山志》《真诰》一类的纪传谱录）、物（玉印、玉圭、玉符、玉简）、地（华阳洞的刻文与睹星门的门）三样合起来，才是一份完整的副本。
**文是目录，物是钥匙，地是锁。**

于是世上有两种道士：
- 一种**守录**：把秘录照原样抄下去，错一个字也要在旁注里说明——因为抄错一个字，就会有一个人的生死对不上号。
- 一种**篡录**：发现只要改掉文里的一个字，先在人间造成"这个名字本来就不是这样写的"的共识，籍上对应的那一笔就松了。改得多了，**人是可以被写成不存在的**。

主线就是守录者对篡录者。而主角是个刚拿到度牒、被派去处理"诡异事件"的年轻道士——他一开始根本不知道自己在跟谁下棋。

## 2. 三条铁律（所有诡异事件的共同成因）

### 铁律一：**録改了，籍就松了**（案发机制）

篡录者动秘录，不会立刻天崩地裂。他只是让某一处**名与实**之间裂开一条缝：

- 缝在人身上 → 那人开始"记不清自己是谁"，旁人也会记错他的名字；
- 缝在屋上 → 屋里的人每天重复同一件事而无人察觉；
- 缝在日子上 → 某一个日期被从所有人的记忆里剪掉（这正是**时间循环**在本作里的世界观解释）。

**这条铁律是把既有时间循环玩法"世界观化"的关键**：主角反复经历的同一段时间，不是游戏机制，而是**秘录被改时溢出的"余页"**——那一页没被写死，所以反复播放，等人来补。

### 铁律二：**不许宣泄**（代价机制）

茅盈受王君之赐时"立坛结盟，不许宣泄"（古史 1.1）。
泄密不是道德问题，是**结构性代价**：凡把秘录内容说给不该听的人，那份内容就从句子里脱落，落到听者身上。
- 说到"某人的死期" → 听者替他死；
- 说到"某个咒诀" → 念咒的人失去那段记忆；
- 主角每解释一次真相给自己人听，就要付一次代价。**这给"向同伴解释"这个动作定价**，避免剧情里人物白拿情报。

### 铁律三：**期会日不可空**（时间机制）

茅盈临行留言：每年**三月十八**、**十二月二日**期会，好道者此日来句曲可获圣佑（古史 1.1）。
千年来香火不断，所以这两天在"籍"上被写得极重。
**重到无法一次写完**——每一年的期会日，都是秘录最薄的地方。篡录者专挑这两天动手；守录者必须在两天之内把录补回去，否则整年的名籍作废。

> 全作的时间压力来自这条：主角手上的每个案子，最后都有一个死线是三月十八或十二月初二。

## 3. 主角的道法体系：**存思回照**（把时间循环做成道术）

上清派本色是**存思**（存神）：人身百脉关窍各有主神，以意守之，"精神内守，神不外驰"（古史 2.1）。
本作把它推到底：**既然身内之神可存思，那么身外的"余页"也可存思。**

**存思回照**：主角在某个"余页"（被改动而反复播放的时段）里，把自己的神识当作灯，反复照同一段时间，直到照见缝在哪。
- 表：时间循环。玩家一遍遍重演同一段时间。
- 里：主角在"存思"。他并没有穿越，他**只是没有离开那一页**。
- 代价：每重演一次，他在现实里消耗一分"身神"——表现为 HUD 上的**心灯**（见系统文档）。心灯灭则人散，不是死亡，是**名籍上被划掉**。

配套的三样修行（古史 2.1，全部有出处）：

| 名称 | 出处 | 玩法作用 |
| --- | --- | --- |
| **存思**（含守三一、守洞房、守玄丹） | 《紫阳真人周君内传》 | 进入"余页"，即时间循环的进/出 |
| **叩齿咽津行气咒祝** | 诵《大洞真经》前程式 | 稳定余页，防止循环里混入不属于这段的东西 |
| **服饵断谷**（制虫丸、初神去本丸） | 《紫阳真人周君内传》 | 削弱"谷虫"（= 篡录者布下的杂讯），扩展目击范围 |
| **存思日月法 / 存思二十四星法** | 《上清大洞真经》 | 定方位：用日月星锚定"这还是同一天" |

独门本领（主角区别于其他道士之处）：
**他能"读错字"。** 他被派去抄录秘录副本，抄了十年，养成一个怪癖：任何抄本，他一眼就能看出哪个字不是原手的笔迹。
这项本领在故事里叫**辨笔**，来自陶弘景得"杨、许手书真迹"以及"凡三君手书……多掾写，多杨书"的记载（古史 1.2、1.3）。
**主角不是最能打的道士，是最会认字的道士。**这决定了本作的解法以"查证"为主，以"斗法"为辅。

## 4. 反派：篡录者

### 4.1 起源：王灵期一脉的"改良派"

东晋末，**王灵期**等向许黄民求经，得数卷后"窃加损益，盛其藻丽"，依托《王君传》《魏夫人传》的题目"张开造制，凡五十余篇"，结果"许、王齐辔，真伪比踪""举世崇奉"（古史 1.2）。
王灵期本人未必有恶意——他只是觉得**旧文太简，改漂亮些，信的人就多了**。

但这门手艺传下来，就成了"篡录者"：他们不认为自己在造假，他们认为自己在**修订**。
祖训四个字：**"盛其藻丽"**。

### 4.2 组织形态：不是邪教，是"修补匠"

篡录者没有统一的教团，只有一套行规。他们在人间往往有正当身份：
- 修碑的匠人（能改碑，就能改石上之录）；
- 编方志的文人（能改卷，就能改纸上之录）；
- 管档案的吏员；
- 尤其是——**替宫观做"整理校勘"工作的学者**。

他们自称**补录人**，对外说"替祖师把抄错的地方改回来"。
他们真的相信自己在做善事，这是本作主要的道德重量所在：**每个反派都能说出一句让人反驳不了的话。**

### 4.3 最终目的：把"第一行"删掉

上清派谱系的第一行是**三茅真君**，且他们是**被追奉**进谱系的，位于代次之外，时间上早于上清经的造作（古史 1.4）。
对篡录者而言，这一行是"后人硬加上去的祖宗"，是整份秘录里最不牢固的一笔。
他们的终极计划叫**"还其本貌"**：把三茅真君从秘录里删掉，让茅山变成一座没有祖师的宫观，让所有仙职任命失效——自此，"名籍"无人掌管，谁都可以给自己写一个名字。

听上去像自由。实际上是把"关决生死"的裁量权，交到**会写字的人**手里。

### 4.4 递进式曝光（每卷只揭一层）

| 卷 | 玩家以为的反派 | 实际真相 |
| --- | --- | --- |
| 一 | 一个疯了的抄经人 / 一个走尸 | 有人在有组织地"修字" |
| 二 | 盗墓贼、地方豪强 | 他们是为"补录人"取件的采办 |
| 三 | 一位受人尊敬的校勘学者 | 他就是当代"补录人"之首 |
| 四 | 篡录者要毁掉秘录 | 篡录者要"完善"秘录，其首领自认在救茅山 |
| 五 | 决战 | 删掉第一行不会解放任何人，只会让籍成为空白——而空白由写字的人来填 |

## 5. 时间与空间结构

### 5.1 时间

- **现实轴**：当代（近未来感不强的现代），主角 24 岁，刚领度牒、被派往茅山片区。
- **古史轴**：西汉 → 东晋 → 南朝 → 唐 → 宋 → 元 → 明清 → 民国，全部以"当事人留下的记录/实物"形式进入案件，不作穿越。
- **余页（循环）**：每个案件都是一段被改动的时间，长度不一。主角"存思回照"进入后，余页反复播放，直到被补写正确。
- **期会日**：三月十八、十二月初二，每卷末的死线。

### 5.2 空间

- 主场景：**茅山**。九峰之中取三峰为骨——大茅峰（案一）、中茅峰（案三）、小茅峰（案六）；华阳洞为纵贯全作的深井（案五、案十）。
- 案件现场优先选用茅山道院现存实物（古史 1.6）：石井栏、李玄靖先生碑、观龙歌碑、上清宗坛碑、刘混康墓志、朱自英显扬碑、明真人传派碑、康有为葬母碑、众妙石刻、睹星门、三天门万寿台。
- 外线地图（陶弘景访道线，古史 1.3、2.4）：会稽大洪山、余姚太平山、始宁嵊山、始丰天台山、恒山、西城山、衡山朱台——用于中后期"追击补录人的采办线"。
- **每案必有一个"余页空间"**：现实场景被改动后的错版，几何上大致相同，细节全错（例如牌匾上的字被换过一个）。

### 5.3 与既有游戏机制的对齐（重要）

项目已有 `TimeLoopManager` / `PersistentMemoryManager` / `NPCTimelineParser`（见 `../../README.md`）。
本作**不新增引擎概念**，只把三件套命名进世界观：

| 引擎概念 | 世界观名称 | 一句话解释 |
| --- | --- | --- |
| `TimeLoopManager` 的 420 秒循环 | **余页** | 秘录被改后未写死的一页，反复播放 |
| `loop_index` | **第几遍存思** | 主角照了第几遍；也是他消耗了几分身神 |
| `PersistentMemoryManager` 的线索 | **录中所得** | 存思照见的东西，出余页后仍在，因为它是"录"上的 |
| `NPCTimelineParser` 的 NPC 动线 | **各行其是的活人** | 活人不受余页影响，他们的动线是"缝"的最佳参照物 |

> 设计要点：**活人的动线在每一遍里都一样**——这既是玩家的推理工具（差异即线索），也是案件的恐怖来源（唯一没有被改的，是活人，因为他们"没写在录上"）。

## 6. 主题与禁令

### 6.1 主题

**记录不是事实，但记录决定了谁能活着。**
主角的所有胜利，都不是把历史改回去，而是**证明历史本来是什么样**——他赢的方式是"我找到了原手的那一笔"。

### 6.2 写作禁令（违反即为设定冲突）

1. **不推翻真实史实**。三茅真君来过、陶弘景隐过茅山、陆修静编过《三洞经书目录》——这些在故事里是真的。恐怖发生在"记录的缝隙"里，不发生在"历史是假的"里。
2. **不发明道教名词**。一切咒诀、法器、职名、日期必须能在 `_sources_古史素材考.md` 找到；需要新造时，先在该文件登记。
3. **不把道教写成邪教**。反派是**改了行规的人**，不是道教本身；正派道士的胜利方式是守规矩地查证。
4. **不写"道长一挥手，鬼就没了"**。解法必须先有证据链，再有仪式；仪式是**确认**，不是**打击**。
5. **主角不死**，但**代价照付**：心灯可灭、记忆可失、可以被人忘掉名字（古史"名籍"逻辑的必然结果）。
6. **期会日必须有事**。每个案件卷的结尾都要落在一个期会日上。
