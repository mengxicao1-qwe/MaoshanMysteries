# 故事自造术语登记表（Story-Invented Terms Registry）

> **用途**：把"故事虚构设定"与"道藏/史料实有名词"彻底分开管理。
> `_sources_古史素材考.md` 只收**可查证的古史与道术素材**；本文件收**写手自造、但有明确推演依据**的设定。
>
> **两条铁律**：
> 1. 任何自造术语都必须在本表登记 **推演依据**（引用 `_sources_古史素材考.md` 的编号）与 **使用边界**（能怎么用、不能怎么用）。
> 2. 本表所有条目均为**文艺创作的虚构设定**，不得在正文中被表述为道教实有的职名、神名、经名、法器或科仪原名。

---

## 登记格式

| 字段 | 说明 |
| --- | --- |
| 术语 | 名称 |
| 类型 | 职名 / 法术 / 仪式 / 器物 / 机制标签 / 群体称谓 / 虚构人物 |
| 推演依据 | `古史 x.x` 编号 + 一句推演逻辑 |
| 使用边界 | **禁止**把它写成什么（关键，防止在正文里"越界成真"） |
| 提出者 | 登记人 / 案件 |

### 3.1 关键裁定：**摊录**（Lead 决定，全书适用）

**规则**：主角在查案时，可以**摊开原件让别人自己看**，而不"说"出来。
**理由**：铁律二（不许宣泄）惩罚的是**说**——把秘录内容说给不该听的人。
"摊开原件"不是"说"，而是**让当事人自己读**；代价因此落到**读的人**身上，而不是说的人。

**三条硬约束（缺一即不成立，写作时必须同时满足）**：
1. **必须有原件在场**。没有实物，就只能说——一说就付铁律二的账；
2. **只有当事人本人能读**（涉案者、见证者），不得当作"公布真相"的通用手段；
3. **读的人自己念、自己付代价**：每用一次摊录，必须写出读数者付出的是什么（记忆、称呼、某个日期）。
4. **禁止**用它规避卷五的"公开校勘"：公开校勘是一次性的、有见证人签名的终局动作，不能靠摊录批量替代。

> **裁定理由**：若不加约束，摊录会架空铁律二，让主角不必付代价就拿情报。
> 加上三条约束后，它反而成了本作的**道德试纸**：主角每次决定"要不要摊给他看"，都是在决定让别人替他付账。
